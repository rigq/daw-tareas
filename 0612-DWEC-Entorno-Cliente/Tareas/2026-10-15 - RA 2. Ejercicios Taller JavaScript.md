## Enunciado

Ejercicios Prácticos (Módulos 00 al 09)

Ejercicio 1: Declaración, Tipos y Coerción Aritmética

- 
Enunciado: Declara una variable numérica que almacene la cantidad de unidades de un producto y una constante con el precio unitario en formato string (ej: "45"). Utiliza conversión de tipos para calcular el precio total bruto, aplica un incremento del 21% usando operadores aritméticos y muestra el resultado en consola empleando plantillas de cadenas (template literals).

Ejercicio 2: Operadores de Asignación Compuesta

- 
Enunciado: Define una variable puntosAcumulados con valor inicial de 100. Aplica secuencialmente operadores de asignación compuesta para: sumarle 50 puntos, restarle 20 puntos, multiplicarla por 2, y dividirla entre 4. Imprime el valor final y su tipo de dato mediante typeof.

Ejercicio 3: Validación de Nulos e Indefinidos

- 
Enunciado: Declara tres variables: una sin inicializar (let a;), otra inicializada explícitamente a null (let b = null;), y una tercera con un string vacío (let c = "";). Comprueba mediante operadores de comparación estricta (===) si a es estrictamente igual a undefined y si b es estrictamente igual a null. Muestra los resultados booleanos.

Ejercicio 4: Lógica Booleana y Tabla de Verdad de Acceso

- 
Enunciado: Define tres variables booleanas: isRegistered = true, hasSubscription = false, y isBanned = false. Escribe una expresión lógica compleja que determine si un usuario puede descargar un recurso: se permite si isRegistered es verdadero Y hasSubscription es verdadero, O bien si el usuario es administrador (añade una variable isAdmin = true). Todo ello condicionado a que isBanned sea estrictamente falso. Imprime el resultado booleano.

Ejercicio 5: Manipulación y Normalización de Strings

- 
Enunciado: Dada una cadena de texto recibida con formato irregular: " usuario_DAW@correo.es ", utiliza los métodos de string aprendidos para eliminar los espacios sobrantes, transformarla por completo a minúsculas, extraer los primeros 11 caracteres mediante el método de corte adecuado, y comprobar mediante métodos lógicos de cadena si incluye el dominio "@correo.es".

Ejercicio 6: Condicional Simple y Operador Ternario

- 
Enunciado: Define una variable numérica stock = 3. Utiliza primero una estructura condicional if / else para comprobar si el stock es mayor que 0 (imprimiendo "Disponible" o "Agotado"). A continuación, reescribe exactamente la misma lógica utilizando el operador ternario asignando el resultado a una variable llamada estadoStock.

Ejercicio 7: Condicionales Anidados para Rangos Numéricos

- 
Enunciado: Dada una variable numérica que representa la velocidad de un vehículo (velocidad = 115), implementa una estructura if / else if / else para clasificarla:

- 
Menor o igual a 50: "Velocidad urbana adecuada"

- 
Mayor a 50 y menor o igual a 90: "Velocidad convencional"

- 
Mayor a 90 y menor o igual a 120: "Velocidad en autopista legal"

- 
Mayor a 120: "Exceso de velocidad / Multa"

Ejercicio 8: Árbol de Decisiones Condicionales Complejo (Validación de Formulario)

- 
Enunciado: Simula la validación de un formulario con tres variables: username = "alumnoDAW", password = "Secreto123", y termsAccepted = true. Utiliza condiciones anidadas para verificar:

- 
Si termsAccepted es falso, rechazar inmediatamente indicando que se deben aceptar los términos.

- 
Si se aceptan, verificar que el username tenga una longitud mayor o igual a 6 y que la password incluya el número "123".

- 
Si todo es correcto, mostrar "Formulario validado con éxito".

Ejercicio 9: Estructura Switch con Agrupación de Casos (Roles de Sistema)

- 
Enunciado: Dada una variable de texto rol = "EDITOR", normalízala a minúsculas y utiliza una estructura switch con casos agrupados para definir los permisos:

- 
Si es "administrador" o "supervisordb": imprime "Acceso total al sistema y base de datos."

- 
Si es "editor" o "redactor": imprime "Permisos de escritura y publicación de contenidos."

- 
Si es "invitado": imprime "Acceso exclusivo de lectura."

- 
Caso por defecto (default): imprime "Error: Rol de usuario no reconocido en el sistema."

Ejercicio 10: Algoritmo Lógico Integrado (Strings + Operadores + Condicionales)

- 
Enunciado: Escribe un script que analice una cadena de código de licencia: "LIC-2026-ADMIN". El programa debe verificar simultáneamente mediante condicionales lógicos:

- 
Si la cadena empieza por el prefijo "LIC-" (usando métodos de string).

- 
Si su longitud total es exactamente igual a 13 caracteres.

- 
Si contiene la palabra "ADMIN". Si cumple las tres condiciones, imprime "Licencia corporativa válida"; en caso contrario, detalla que la licencia es incorrecta.
