1. ¿Qué es CSS Grid?

CSS Grid es un sistema de maquetación bidimensional: permite organizar los elementos en filas y columnas a la vez. Flexbox, en cambio, es unidimensional (organiza en una sola dirección: o en fila o en columna).

Estos son los conceptos básicos:

  • Contenedor grid (grid container): el elemento padre al que se le aplica display: grid. Casi todas las propiedades de este tutorial se escriben en él.
  • Ítems (grid items): los hijos directos del contenedor. Se colocan automáticamente en la cuadrícula.
  • Pistas (tracks): cada columna y cada fila de la cuadrícula.
  • Celda (cell): el hueco donde se cruzan una fila y una columna.
  • Líneas (lines): las líneas que separan las pistas. Una cuadrícula de 2 columnas tiene 3 líneas verticales.

En todos los ejemplos, el fondo gris es el contenedor y los cuadros de colores son los ítems.

2. display: grid

Es el primer paso: convierte un elemento en contenedor grid. Sus hijos directos pasan a ser ítems de la cuadrícula.

.ejemplo {
    display: grid;
}

Si no defines columnas, el grid tiene una sola columna y cada ítem ocupa una fila nueva, uno debajo de otro. Para que parezca una cuadrícula hay que definir columnas (siguiente apartado).

3. grid-template-columns

Define cuántas columnas tiene el grid y cuánto mide cada una. Se escribe un valor por columna, separados por espacios.

.ejemplo-columnas {
    display: grid;
    grid-template-columns: 200px 1fr 2fr;
}

Aquí hay 3 columnas porque hay 3 valores:

  • 200px: la primera columna mide siempre 200 píxeles.
  • 1fr y 2fr: se reparten el espacio que sobra.

La unidad fr

fr significa fracción del espacio disponible. Primero se descuentan las medidas fijas (en el ejemplo, los 200px) y el resto se divide en partes: 1fr 2fr son 3 partes en total, así que la segunda columna ocupa el doble que la primera. Con 1fr 1fr las dos columnas son iguales.

Valores que se pueden usar

ValorSignificado
200pxTamaño fijo en píxeles.
25%Porcentaje del ancho del contenedor.
1frUna parte del espacio libre.
autoSe ajusta al contenido (y ocupa el espacio sobrante si no hay fr).

4. La función repeat()

Sirve para no repetir valores. repeat(cantidad, tamaño) crea esa cantidad de pistas con ese tamaño.

/* Estas dos líneas hacen exactamente lo mismo */
grid-template-columns: 1fr 1fr 1fr 1fr;
grid-template-columns: repeat(4, 1fr);

5. grid-template-rows

Es lo mismo que grid-template-columns, pero para las filas: define cuántas filas hay y cuánto mide de alto cada una.

.ejemplo-filas {
    display: grid;
    grid-template-columns: 1fr;
    grid-template-rows: 60px 120px 60px;
}

Tres filas: la primera de 60px, la segunda de 120px y la tercera de 60px.

60px
120px
60px

Distintas formas de escribir las filas

ValorResultado
repeat(2, 1fr)2 filas iguales que se reparten el alto del contenedor.
1fr 1frIgual que la anterior, escrito a mano.
auto auto2 filas, cada una con el alto de su contenido.
20vh 20vh2 filas de un 20% del alto de la ventana cada una.
100px 100px2 filas de 100px.
100px autoPrimera fila de 100px; la segunda se ajusta a su contenido.

Ojo con dos errores típicos:

  • Los valores se separan con espacios, no con comas: 100px, 100px es inválido y el navegador ignora la línea entera.
  • fr en filas solo reparte espacio si el contenedor tiene una altura definida (por ejemplo height: 100vh). Si no, la altura se ajusta al contenido y no hay espacio que repartir.

6. gap

Define el espacio entre pistas (entre filas y entre columnas). No añade margen por fuera del grid, solo entre los ítems.

.ejemplo-gap {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 30px;
}
  • gap: 30px: mismo espacio entre filas y columnas.
  • gap: 10px 30px: 10px entre filas y 30px entre columnas.
  • row-gap y column-gap: lo mismo, por separado.

7. grid-auto-rows

grid-template-rows define las filas que tú declaras (las explícitas). Pero si hay más ítems de los que caben en ellas, el grid crea filas nuevas por su cuenta (las implícitas). Sin más instrucciones, esas filas miden lo que mida su contenido.

grid-auto-rows fija el alto de esas filas automáticas.

.ejemplo-auto-filas {
    display: grid;
    grid-template-columns: 1fr 1fr;   /* 2 columnas */
    grid-template-rows: 50px;         /* solo defino la 1ª fila */
    grid-auto-rows: 100px;            /* el resto de filas miden 100px */
}

Hay 5 ítems y 2 columnas, así que hacen falta 3 filas. La primera (50px) la define grid-template-rows; las otras dos se crean solas y miden 100px por grid-auto-rows.

1 (50px)
2 (50px)
3 (auto: 100px)
4 (auto: 100px)
5 (auto: 100px)

¿Cuándo usarlo? Cuando no sabes cuántos elementos habrá (una galería, una lista de tarjetas...). Con grid-auto-rows cada fila nueva sale con el alto que quieres sin tener que declararla.

8. Ejercicio: 4 bloques en 2 columnas y 2 filas

Juntando lo aprendido: 4 bloques repartidos en 2 columnas y 2 filas que ocupan toda la pantalla.

.contenedor {
    display: grid;
    grid-template-columns: 1fr 1fr;  /* 2 columnas iguales */
    grid-template-rows: 1fr 1fr;     /* 2 filas iguales */
    gap: 10px;
    height: 100vh;                   /* alto de toda la pantalla */
}
  • grid-template-columns: 1fr 1fr crea 2 columnas del mismo ancho.
  • grid-template-rows: 1fr 1fr crea 2 filas del mismo alto.
  • height: 100vh hace que el contenedor mida el 100% del alto de la ventana (vh = viewport height). Sin esto, las filas 1fr no tendrían espacio que repartir (ver el aviso del apartado 5).
  • Los 4 ítems se colocan solos, de izquierda a derecha y de arriba abajo.
