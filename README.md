# DAW — Tareas

Tareas y prácticas del ciclo de **Desarrollo de Aplicaciones Web**.

## Estructura

| Carpeta | Asignatura |
|---|---|
| `Programacion/` | Programación |
| `Bases-de-Datos/` | Bases de Datos |
| `Lenguajes-de-Marcas/` | Lenguajes de Marcas (HTML, CSS, XML) |
| `Sistemas-Informaticos/` | Sistemas Informáticos |
| `Entornos-de-Desarrollo/` | Entornos de Desarrollo |
| `Apuntes/` | Apuntes generales |

Dentro de cada asignatura, una carpeta por unidad o tarea, por ejemplo:
`Programacion/UT1-Introduccion/`, `Programacion/UT2-Tarea-Bucles/`.

## Trabajar en varios portátiles

**Al empezar a trabajar** (traer lo último):

```bash
git pull
```

**Al terminar** (guardar y subir):

```bash
git add .
git commit -m "Describe lo que has hecho"
git push
```

**En un portátil nuevo** (solo la primera vez):

```bash
git clone https://github.com/<tu-usuario>/daw-tareas.git
```
